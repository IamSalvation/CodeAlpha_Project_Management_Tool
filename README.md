# CodeAlpha_Project_Management_Tool
# Project Management Tool (Kanban Board)

A web-based Kanban board to manage tasks across different stages.

## Features
- Add new tasks with a title.
- Categorize tasks into "To Do", "In Progress", or "Done".
- Dynamically move tasks between columns.

## How to Run
1. Ensure you have Node.js installed.
2. Install dependencies: `npm install`
3. Start the server: `node server.js`
4. Open `http://localhost:5000` in your browser.
